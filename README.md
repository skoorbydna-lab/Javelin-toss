# Tap Athletics

Four athletics events plus an Olympics mode: high jump (hold-and-release run-up and take-off bars, then tap at the top of the leap to arch over; official countback for ties), 100m (react to the gun and three random cues), long jump (timed start taps, a reaction cue, take off at the board and hold to set the angle) and javelin (run, hold to raise the javelin, release before the line). Olympics plays all four and scores them with decathlon points. Shared online leaderboards keep each player's best for Olympics, 100m, long jump and javelin.
